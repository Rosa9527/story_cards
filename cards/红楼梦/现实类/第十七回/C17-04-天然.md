# C17-04 天然

**类型**：说真话 / 被赶  
**分类**：现实类

## 卡面

走到一处照着乡下样子修的地方。土墙、草顶、篱笆、一口井，田里的菜一行一行，长得齐整。

甲一进去就说好，说这地方勾起了他的心思，说人辛苦半生，倒不如这样过日子。

甲回头问那个跟来的孩子：你看这里如何？

旁边的人都在推他，小声教他说：说好，说好就是了。

那孩子没有听。他说：不如刚才那处。

甲的脸沉下来了，说他一味只认富贵，不懂这样的清静，终究是不读书的缘故。

那孩子站住，反问了一句：古时候说的“天然”，到底是什么意思？

旁边的人忙替他解释：天然就是自己长成的，不是人做出来的。

那孩子就接着说：那这一处田庄，分明是人做出来的。远没有村子，近不挨城，背后没有山，前面没有水，是硬生生搁在这儿的。

他没有说完。甲喝了一声，叫他出去。

他刚退到门口，甲又喝了一声：回来。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是这一家的长辈，也是这处地方的主人。他不是不许人说真话——他自己刚说完“这地方好，勾起我的心思”，所以这一句反驳才格外疼：被驳的不是一句话，是他自己刚花了心思也刚夸过的地方。

**玩家在哪**：玩家可以是那个被推着说话的孩子——旁边的人按着你的袖子教你答，你答不答这个“好”；可以是那一群客里的一个，你知道该推他，也知道推不动；可以是站在门外听这一声“出去”“回来”的下人；也可以不在场，事后听说“今天少爷说了句什么，老爷把他赶出来了，又叫回去了”。若玩家就是那个孩子，卡的重点变成“明知道说出口要挨这一声，你还说不说”。

**那一句真话有多重**：他说“不如刚才那处”，等于当众把甲的眼光按了下去；他再把“天然”两个字拿来做题目，就是把甲刚说的话拆开给人看。这不是抬杠，是把“这是假的”说出口了。

**选择**：由孩子做——顺着众人的推，说一个好字；还是把“这是假的”说出口。第二个岔路是甲的：喝出去就完了，还是像这样叫回来。

**代价**：说真话，甲当众被驳在自己出钱修的地方上，这一口气没处放；孩子落一个“说得出真话、留不住嘴”的名声，也从此知道在这个人面前真话能说到哪一步。说好，这一场就过去了，可这屋里从此多了一条不能说的话。

**这是哪**：古代、现代、奇幻、科幻都可以。新修的园子、装修好的会所、仿古的宅子、宣传片里的外景、用术法堆出来的道场——只要“这地方是造的，有人要当它是真的”这一层在，就成立。

**注意**：卡停在“他退到门口，甲又叫了一声回来”这一刻。不要写他有没有把话说完，不要写甲后面罚没罚他。“出去”和“回来”这两声，就是这一场最重的地方——赶他走，是还要用他；叫他回来，是还要罚他。

## 设计底稿

**戏剧命题**：当着一屋子人，一个人该不该把“这是假的”说出口。

**关系槽**

```
甲 → 主家，刚说完自己羡慕这样的日子
那个孩子 → 被问的人；他也是被众人推着要他说“好”的那一个
众人 → 推人的人；他们不是要害他，是怕他讨没趣
那处地方 → 甲自己叫人修的，也是甲刚刚夸过的
```

**四拍**

1. 到了一处照乡下样子修的地方，甲当众说好，说自己动了归田的心思。
2. 甲回头问孩子；旁边的人推他、教他说好。
3. 孩子说“不如刚才那处”，又把“天然”二字拿出来问。
4. 孩子说这地方是人力硬做出来的；甲喝他出去，他退到门口，又被叫回来。

**选择**：由孩子做——顺着众人的推，说一个好字；还是把“这是假的”说出口。说好，这一场就过去了，甲高兴，众人松一口气；说假，就是当众驳了甲刚说过的话，驳的是一处甲自己叫人修的地方。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【谶：狂】甲当众用这个字骂过他，往后这四个字会被人拿来说他一辈子 | 被后面的“他再顶一次嘴 / 他惹了事”触发 |
| 【失】孩子失去了甲在这一场里给他的那点好感 | 消耗后，甲再叫他出来会先想一想 |
| 【怨】甲被驳在自己修的地方上，这一口气没处放 | 喂给后面的“甲找个由头发作他一次” |
| 【悟】孩子第一次把“真”和“假”分得这么清楚，且是当众说的 | 日后他还会这样看别的东西 |
| 【寄】孩子在这个家里的位置，全靠甲一句话；这一声“出去”，他走到了门口又回来 | 被《住进来的人》留下的【寄】消耗 |

**移植**：古代——父亲带客游新修的别业，儿子当面说这园子是假的。现代——老板带客户参观新装修的“田园风”会所，儿子说这是假的；公司拍宣传片，导演的家人当场拆台；家宴上，长辈夸新买的“老宅子”，晚辈说是仿的。奇幻 / 科幻——宗门修了一座“自然道场”，弟子当众指出它是法术堆出来的；殖民地里造了一片“地球林”，随行的孩子说这里没有一样是真的。

**禁忌**：不要把甲写成不许人说真话的暴君——他自己是信这一套的，所以他被驳得格外疼。也不要写孩子说得对：卡只写他说了，不写他该不该说。这一场的重量在“出去”和“回来”两声，不在道理。

**原著锚点**

- 保留：晚辈当众说出一处景致是“人力穿凿”“非其地而强为其地”，长辈恼羞成怒，喝他出去，随即又叫他回来。
- 舍弃：稻香村、杏花、酒幌、浣葛采芹的联句、“天然图画”整段议论的具体字句。
- 原文：“此处置一田庄，分明是人力造作成的。远无邻村，近不负郭，背山无脉，临水无源……即百般精巧，终不相宜……”；贾政“气的喝命：‘出去！’才出去，又喝命：‘回来！’”
