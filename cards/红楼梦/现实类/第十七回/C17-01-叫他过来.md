# C17-01 叫他过来

**类型**：当众考 / 展示  
**分类**：现实类

## 卡面

一处刚收拾好的地方，花木、墙、路都是新起的。管事的人来请甲去看，说有几处地方还空着，要请甲拿个主意。

甲看了一遍，说：有几处得让人看一眼，才能有个说法。

一起去的还有几个客。他们的儿子，一个也不在跟前。

甲忽然想起自己家的那个。这孩子念书不用心，闲话上倒是被人夸过两句。

甲就说：叫他过来。

有人小跑着去了。不多一会儿，那孩子被带到众人面前，站在甲身后半步的地方，不知道叫自己来是做什么。

来的人都在看。看这家的长辈，拿出一套什么脸色。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是这一家的长辈，手里有这个新地方，也有“叫谁来看”的资格。甲平时不管这孩子的事，此刻要管，是因为这处地方非有字不可，而现成的人都试过了，甲一个也不满意。

**玩家在哪**：玩家可以是那个被叫来的孩子——站在半步之外，不知道为什么叫自己来；可以是那一群客里的一个，看着这家的长辈怎么当众管自己的孩子；可以是跑腿去叫人的那个，只照吩咐办事；也可以不在场，事后只听说“那天老爷把少爷叫进园子里去了”。若玩家就是那个孩子，卡的重点变成“你被推到人前，还没人告诉你为什么”。

**那个孩子是谁**：他不必是甲亲生的——甲的儿女、侄子、收养的孩子、徒弟、托在膝下养的一个晚辈，都可以。关键只有一条：甲平时对他没多少指望，可有人夸过他。

**那群客是谁**：有交情、有见识、将来会把今天这一场说出去的人。他们不能是摆设——他们得是那些“甲愿意让他们看看”的人。

**甲为什么挑这个时候**：这处地方要用了。字要有人写，名要有人定，甲自己不肯写，现成的人又不合用。

**代价**：叫了，甲就把自家的名声押在这孩子身上；孩子当众出丑，众人只会替甲难堪，那一圈笑话日后都归在甲头上。不叫，甲回去交不出任何东西，也堵不住那些说这孩子将来不成的闲话。

**这是哪**：古代、现代、奇幻、科幻都可以。“新收拾好的地方”可以是园子、宅子、铺子、公司、展厅、舰队；但“有一群人在旁边看着”这一层必须留着。

**注意**：卡停在“来的人都在看，长辈拿出了一套脸色”这一刻。不要写这孩子答得好不好，也不要写甲叫他是为了抬他还是压他。这一场从甲开口起就收不回去了：往后孩子做的任何一件事，都会被挂到这一场上来讲。

## 设计底稿

**戏剧命题**：一个当众对孩子没信心的长辈，为什么偏要把孩子叫到众人面前来。

**关系槽**

```
甲（长辈 / 主家 / 有资格看这份东西的人）
甲 → 那个孩子 → 不成器，但被人夸过一句闲话上的本事
甲 → 众客 → 有交情、有见识，将来会替甲把这一场说出去
甲 → 那处地方 → 是甲一生体面的一部分
```

**四拍**

1. 甲来看这个新收拾好的地方，本来只是验收。
2. 甲发现有留空的地方，得有人写、有人定；客人们给的现成话，甲都不满意。
3. 甲想起自家那个孩子：不成器，但有人夸过他嘴上还行。
4. 甲开口：叫他过来。孩子被带到人前，站在半步之外，不知道要做什么。

**选择**：由甲做——叫，还是不叫。叫了，就是把孩子推到一群等着看笑话的人面前；不叫，这一场就只是走走看看，什么也不会发生。要落得体面，甲本可以回去私下试、试好了再当众说，或者干脆不提这事。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【谶：今日】这一场是临时起意，但从甲开口起，它就必须有个结果 | 被 C17-02 / C17-03 / C17-04 / C17-05 连续消耗 |
| 【怨】孩子被叫到人前，却没人告诉他为什么 | 喂给后面的“不肯再开口 / 背地里告状” |
| 【恩】那个肯跑腿去叫人的人，替甲把场面圆了一回 | 日后甲家有人要用人时 |
| 【失】甲在这一天之后，失去了“不管孩子的事”这个清白 | 消耗后，甲再不能说“我向来不管他” |

**移植**：古代——父亲带着清客游新园、看新宅、验新修的祠堂。现代——公司开业前带客户看场地，一时兴起把不上进的儿子叫来当场说两句；家里办寿宴前，亲戚都在，长辈把孙子叫出来背诗；选秀、竞聘、面试，评委把自己的孩子叫上场。奇幻 / 科幻——教团验收新殿，掌门把不成器的弟子推到长老面前；飞船竣工巡礼，舰长把儿子叫到全舰广播前。

**禁忌**：不写甲为什么对孩子没信心（那会变成前因）；不写孩子在这一场里的表现好不好；不要把甲写成恶人，也不要写成慈父——他只是个要面子的人。

**原著锚点**

- 保留：长辈在一个公开的、有外人在场的场合，临时把不成器的晚辈叫到跟前，当众试他；这一场是被“这处地方要留字”引出来的，不是专门安排的。
- 舍弃：园、匾、对额、贵妃省亲、清客的姓名、所有的诗句。
- 原文：贾政“近来闻得代儒称赞他专能对对，虽不喜读书，却有些歪才，所以此时便命他跟入园中，意欲试他一试”。
