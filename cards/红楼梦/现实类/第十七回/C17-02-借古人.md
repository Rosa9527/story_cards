# C17-02 借古人

**类型**：陪考 / 让位  
**分类**：现实类

## 卡面

一行人走到第一处要留字的地方。那地方正对着来路，头一眼就看见，绕不过去。

甲先问众人：这里写什么好。

众人早就等着这一问。他们一口气报了一长串听着很响的说法，一个比一个漂亮，却没有一个真说到那处地方。

他们知道甲要试的是谁。所以他们说的全是不真不假的话。

甲听完了，一个也不要。他回头去叫那个跟来的孩子。

那孩子也说了一句话，说与其自己编新的，不如用古人现成的话，写在这儿倒也大方。

众人立刻齐声叫好，叫得比刚才大声，把刚才那些主意一句不提。

甲笑了一下，也说了孩子一句。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是出题的人，也是这一家里说话能算的人。他起头问一句，底下的人就得报；他摇头，底下的人就得换。

**玩家在哪**：玩家可以是那一群客里的一个——你知道这一场是给谁的，你得决定自己让不让；可以是那个被叫来的孩子，站在旁边听着一串漂亮话；可以是端茶送水的，站在外圈听完全场；也可以不在场，事后从别人口中听说“今天几位老先生说了什么，老爷一个也没用”。

**那群客为什么说差话**：他们吃这一家的饭。主家要试自家孩子，你若真报一个绝的，就是把主家和你自己一起架在火上；你说差的，主家高兴，孩子有台阶，人人都有面子。

**那个孩子说的这句话分量在哪**：他不是答得更漂亮，他是换了个法子——把标准从“谁编得好”挪到“用现成的就行”。这一挪，众人刚才报的那些就都不必比了。

**代价**：众客这一场把自己的名声打了折——孩子真说了好的，他们的“差”被反衬得更差；孩子说不出，他们更亏，陪了半天，谁也没落着东西。

**这是哪**：古代、现代、奇幻、科幻都可以。园子、评审会、招标现场、宗族议事，只要有“主家出题、陪客答话”这一层，就成立。

**注意**：卡停在“众人齐声叫好，甲也说了孩子一句”这一刻。不要写甲心里信不信这句话，也不要写众客是不是真的服。让路的这一场，从这一句话起，后头的事就都带着它的影子。

## 设计底稿

**戏剧命题**：一群聪明人，为什么宁可带头说蠢话，也不肯说一句真话。

**关系槽**

```
甲 → 主家，题目出在他手里，话也由他来断
众客 → 陪客，吃这家的饭，看这家的脸色；他们的学问是真的，话是假的
那个孩子 → 甲要试的人；他知道众客在让，也知道这一场是给他的
```

**四拍**

1. 到了第一处要留字的地方，甲当众出题。
2. 众客抢着报出一串漂亮而空的说法——他们故意说差。
3. 甲一个都不取，回头叫那孩子。
4. 孩子说了一句“不必自己编，用古人现成的话”，众人齐声叫好。

**选择**：由众客做——说差，还是说好。说差，主家高兴，孩子有台阶，人人都有面子；说好，就等于当众不给孩子留位置，也等于说主家不必叫孩子出来。这是一群人在同一瞬间做出的同一个选择，不需要商量。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】众客让给孩子的这一场，孩子记不记得是另一回事 | 被 C17-03 直接点燃：让出来的位置，被一句话扫了 |
| 【怨】众客的主意一个也没用，他们心里知道自己为什么白说 | 喂给后面的“他们不肯替这孩子说话” |
| 【谶：这地方的字】按众人的话，这些字都是临时的，将来要另请人来定 | 后面“请谁来定、定成什么” |
| 【悟】甲看穿了众客在让，也看穿了他们为什么让 | 消耗后，甲往后不会再叫这一招 |

**移植**：古代——清客陪着东家游园、题匾，对着新铺子、新宅子说客气话。现代——评审会上，陪标的单位知道自己是陪的，报的价、说的话都恰到好处地差一点；家长会前，几位老师当着校长的面把话往一个学生身上让；面试里的“配合人员”。奇幻 / 科幻——长老会审一名新人，几位长老先报出明显不够格的名目；星舰评审，几位议员为一名实习官让出话头。

**禁忌**：不要把众客写成蠢人，他们的学问是真的；也不要写成小人，让路对所有人都有好处。这一场里没有坏人，只有面子。

**原著锚点**

- 保留：一群有真学问的人，为了不让主家难堪，故意报出一串俗套，把出题的机会让给要试的那个孩子。
- 舍弃：匾额、对联、“翼然”“泻玉”“沁芳”等字样、古人的句子、所有诗句。
- 原文：“原来众客心中，早知贾政要试宝玉的才情，故此只将些俗套敷衍。宝玉也知此意。”
