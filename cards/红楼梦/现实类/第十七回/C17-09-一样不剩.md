# C17-09 一样不剩

**类型**：认错人 / 当场撕破  
**分类**：现实类

## 卡面

屋里的人端了茶来，一抬头，看见那孩子身上一件佩的东西也没有了。

屋里的人笑着说：又是那起没脸的东西们，解了去了。

话还没落地，另一个人走进来，一眼就瞧见了，站住了，问：我给你的那个荷包，也给他们了？你明儿再想我的东西，可不能够了！

说完就回房去了。

那孩子赶过去的时候，那个人已经从屋里拿出一件做到一半的物件，正拿着剪子剪。剪子一下去，布就破了。

那孩子站住了，看着那件东西。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**那个动手的人是谁**：她做东西给这孩子，不是头一回；她对这孩子的心意，落在手上的活里。她不是小心眼的人——她剪的是自己这些天的工夫，这比剪别人更疼。

**玩家在哪**：玩家可以是那个动手的人——你看见他身上空了，你要不要先问一句；可以是那孩子，你赶过去的时候，东西已经破了；可以是端茶进来的那个，你只是笑着说了一句实话；也可以不在场，事后听说“那两个人今天闹了一场”。

**她为什么问都不问就剪**：这句话“我给你的那个荷包，也给他们了”，本身就是最伤人的问法。她当着他的面这样问，就是已经先信了；一转身回房拿剪子，是不想在人前哭。

**她剪的不是本来要给他的那件**：这一件是另一件，做到一半的。她剪的是手里的活，也是自己心里的那口气。

**选择**：由那个动手的人做——剪下去，还是先问一句。第二个岔路是那孩子的：冲进去抢下剪子，还是站在门口看着。

**代价**：剪了，那件做到一半的东西再也做不完，这不是钱能赔的，因为做的人只有一个；她剪破的也是自己这些天的心思。不剪，这口气就压回去，压到自己身上。抢剪子，两个人当场在屋里拉扯，外头的人都会知道。

**这是哪**：古代、现代、奇幻、科幻都可以。绣到一半的东西、织了一半的围巾、写了一半的稿子、打了半件的法器——只要“有人替你做了大半，你把它转手了”这一层在，就成立。

**注意**：卡停在“布破了，那孩子站住了”这一刻。不要写这两个人和好没有，也不要写那孩子有没有抢下剪子。这一剪之后，屋里的人都会知道这两个人之间有一件东西坏了。

## 设计底稿

**戏剧命题**：一个人把自己做了一半的东西亲手剪破，这一剪是剪给谁看的。

**关系槽**

```
甲 → 做这件东西的人；东西没做完，就等于是她心里的一件事
那个孩子 → 东西原本是要给他的；他身上现在一件也没有
端茶的那个人 → 第一个开口的人；她说的是一句玩笑话，话却点着了什么
那件做到一半的物件 → 不是他要的那个，是另一件；她剪的是另一件
```

**四拍**

1. 屋里的人端茶来，看见他身上空了，笑着说是底下人解去了。
2. 另一个人进来，站住，问：“我给你的那个荷包，也给他们了？”
3. 这个人回房去了；孩子赶过去。
4. 这个人已经拿出另一件做到一半的物件，正拿剪子剪；布破了。

**选择**：由那个动手的人做——剪下去，还是先问一句。第二个岔路是那孩子的：冲进去抢下剪子，还是站在门口看着。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【怨】剪破的那一下，落在两个人中间 | 被 C17-10 当场回收 |
| 【失】一件做到一半的物件，没了 | 不会补回来；可喂给后面的“她再也不做东西给他” |
| 【悟】剪的人知道了一件自己不肯承认的事：她做的东西，是可以被人随手送掉的 | 消耗后，她做活的心思会变 |
| 【寄】剪的人在这个家里，能凭的只有自己手上这点心思 | 消耗《住进来的人》留下的【寄】 |

**移植**：古代——屋里人端茶时看见佩物全空，另一个姑娘当场剪破绣了一半的香袋。现代——发现送的东西被转手，回去就把还没织完的围巾剪了；同事发现自己的方案被送了人情，把草稿删了。奇幻 / 科幻——炼器师替人打的法器被转赠，当场毁了半成品；画师把自己的画从墙上撕下来。

**禁忌**：不要把剪东西的人写成小心眼——她剪掉了自己这些天的工夫，这比剪别人更疼。也不要写孩子有没有拦住，卡停在这件东西破掉的那一刻。更不要让卡面替她解释“她为什么生气”，只写她看见了什么。

**原著锚点**

- 保留：屋里人端茶，看见佩物一件不剩，笑着调侃；另一人进来一瞧，果然一件没有，说“我给你的那个荷包也给他们了”，赌气回房，拿剪子铰那件没做完的香袋。
- 舍弃：三个人的名字、香袋的针法、荷包的具体样貌，以及“我连这个荷包奉还何如”那一段下文。
- 原文：“生气回房，将前日宝玉嘱咐他没做完的香袋儿，拿起剪子来就铰。”
