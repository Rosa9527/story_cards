# C17-03 都似不妥

**类型**：当众驳 / 得罪  
**分类**：现实类

## 卡面

走到第二处地方，众人报了两个现成的说法。

甲说：俗。又报了两个，甲说：也俗。

甲于是回头问那个跟来的孩子：你说，他们说的有没有能用的？

那孩子想也没想，就说了一句：都不妥当。

先前出主意的人都不说话了。他们脸上没变，只是把眼睛挪开。

甲冷笑了一声，问他：怎么不妥当？

那孩子就说下去了，一条一条，也还说得通。他一个也没有留下，连那两个“俗”字都替甲省了。

众人在旁边说：妙。说得比刚才还响。

甲把话说成了一半，说这孩子狂，说这一回暂且容他。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是问话的人。他要的就是这个答案——他先当众把众人的话驳了两个“俗”，再把话头递给孩子。孩子怎么答，甲都得接着。

**玩家在哪**：玩家可以是那个被问的孩子——你说这句话的时候，满屋子人都在等你；可以是出主意的客人里的那一个，你的话被一句“都不妥当”扫了；可以是站在外圈听见这一句的下人；也可以不在场，事后听说“今天少爷把几位老先生都驳了”。如果玩家就是那个孩子，这一句话说出去，往后这屋里一半人不会再替你说话。

**那个孩子有才没才**：卡里不判。他驳得成不成立，由桌上的人来说；卡只写他说了，和他说了以后各人怎么办。

**众客为什么当场不说话**：他们不是被驳倒了，是被驳了面子。他们的反应是“把眼睛挪开”，不是吵起来。

**选择**：由孩子来做——说“有一句能用的”，还是说“都不妥当”。说“有一句能用的”，是做人，也是给自己留台阶；说“都不妥当”，是让所有人都得重新站一次。甲再逼一遍，他还可以改口。

**代价**：说“都不妥当”，众人的面子当场落在地上；往后这屋子里推举什么人、替谁说话，都会先想起这一句。这一句换来的是“他看不起人”，换来的是“他有本事”——两样都是真的。

**这是哪**：古代、现代、奇幻、科幻都可以。匾对、评审会、提案会、辩论场、长老议事——只要有“一个人当众否掉所有人”的位置，就成立。

**注意**：这张卡停在“甲说这孩子狂，这一回暂且容他”这一刻。不要写这一句驳得对不对，也不要写众客日后怎么算这笔账——账已经记下了，什么时候翻出来是后面的事。

## 设计底稿

**戏剧命题**：一个人当众把所有人的话都驳倒了以后，他还剩下几个能替他说话的人。

**关系槽**

```
那个孩子 → 被问的人，也是被试的人
众客 → 出主意的人，此刻被一句“都不妥当”扫了面子
甲 → 问话的人；他要的是这个答案，也得是这个答案
```

**四拍**

1. 甲不许众客的俗说法过，连驳两个。
2. 甲回头问孩子：他们说的有没有能用的。
3. 孩子说：都不妥当。满场安静。
4. 甲冷笑，逼他说出道理；孩子说得成立，众人转口叫好，甲半斥半纵地收住。

**选择**：由孩子来做——说“有一句能用的”，还是说“都不妥当”。甲逼他时，再说一遍，还是改口。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【怨】众客被一句“都不妥当”驳了面子，这一笔记在他们名下 | 喂给后面的“这孩子没人肯替他说话 / 有人背地里告他的状” |
| 【失】孩子失去了“会做人”这一层名声，换来“有本事”这一层 | 消耗后，往后要选人、要荐人，都会先想起这一句 |
| 【谶：狂】甲当众用的那个字，往后会被人拿来说这孩子一辈子 | 被后面的“他再顶一次嘴 / 他惹了事”触发 |
| 【恩】那个在众人转口叫好时也说了“妙”的人，替孩子把场面护了一下 | 日后需要有人替孩子说话时 |

**移植**：古代——父亲带着清客游园，逼儿子当面驳倒所有客人拟的匾对。现代——方案评审会上，老板问实习生“他们说的行不行”，实习生说都不行；提案会上，甲方问随行的小辈，小辈把乙方的主意从头驳到尾；辩论场上，老师逼一个学生当场驳倒全班。奇幻 / 科幻——门中长老拟了几个法术名，掌门问最小的弟子，弟子说都不成；星际使团拟了几条盟约名目，随行的年轻译者一条条驳回。

**禁忌**：不写孩子驳得对不对，“说得成立”是旁人的评语，不是卡要下的判断。也不要让众人当场翻脸——他们的反应是“挪开眼睛”和“说得比刚才还响”，不是吵。恶不是脸谱，而是面子受损之后的余波。

**原著锚点**

- 保留：被问的人当众把所有人的主意一并否掉，且否得成立；出主意的人当场不说话，随后又齐声改口叫好；长辈半斥半纵。
- 舍弃：具体的匾额字样、清客的姓名、对联内容。
- 原文：贾政问“方才众人说的，可有使得的没有？”宝玉答“都似不妥”；贾政冷笑道“怎么不妥？”
