# C17-05 题不出来

**类型**：卡住 / 限期  
**分类**：现实类

## 卡面

走到一处最要紧的地方。一座石造的门楼，上门雕着东西，四面都是纹样，在这一整片地方的正中间。

这是第一要紧的地方，将来什么人来了，都从这里过。

甲问众人：这里该写什么？

众人说了一串好话，说这地方非比寻常，该用最响的话来配它。

甲摇了摇头，没有说话。

甲回头，叫了一声那个跟来的孩子。

那孩子站在门楼下，仰着头看，看了很久。他没有在听甲问什么，也没有在听旁人说。

他记得自己来过这里。一定是来过的。可他想不起来，是哪一年，哪一天，跟谁一起来的。

甲又叫了一遍。

那孩子还是没有开口。

众人忙替他说话，说这半天下来，人也乏了，词也使尽了，明日再写也罢。

甲冷笑了一声，说：也罢，限你一日。明日写不出来，定不饶你。这是第一要紧的地方，好生写。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是出题的人，也是这一家里最看重这处地方的人。他一路试下来，到这里已经不光是想看孩子有没有本事——他还要看这孩子在这处最要紧的地方端不端得住。

**玩家在哪**：玩家可以是那个被问的孩子——你站在门楼底下，仰着头，脑子里过的是别的什么东西；可以是那一群客里的一个，你替他挡了一句，你也不知道他怎么了；可以是外头等着的人，只听说今天在最要紧那处没写出字来；也可以不在场，事后听说“老爷限了他一日”。

**那张限期是什么**：它不解决任何事，只把这一场挂到明天。今天在这里没说的话，明天还得当众说一遍。

**那个孩子为什么站着不说话**：卡里不解释。你可以把它演成一时发晕、想起旧事、心里有别的事，或者他就是不肯在这处地方随便写一句。要给桌上一个能演的东西，就用一句“他记得自己来过这里”；要怎么算，是桌上的事。

**选择**：由孩子做——硬写一句交上去，还是认下“现在写不出来”。第二个岔路是甲的：限一日，还是当场逼、逼不出来就罚。

**代价**：认下写不出来，孩子在所有人面前第一次有了“不会”的东西，这一屋人往后说起他，会有一个现成的例子；他也保住了那处地方，没在上面留下一句自己都不认的话。甲限这一日，是把一件东西挂在孩子头上：明日写出来，又是当众；写不出来，甲说过“定不饶你”。

**这是哪**：古代、现代、奇幻、科幻都可以。正殿牌坊、城标、舰徽、开幕词、一句谁都得听的口号——只要“这东西最要紧，非得他说”这一层在，就成立。

**注意**：卡停在“限你一日，这是第一要紧的地方，好生写”这一刻。不要写他明天到底写出来没有，也不要解释他为什么觉得自己来过这里。这一张给桌上留下的，是一个悬着的日子。

## 设计底稿

**戏剧命题**：一个从来不肯认输的人，第一次在众人面前想不起一句话，这一场他是怎么下来的。

**关系槽**

```
甲 → 出题的人；这一处是他自己最看重的地方
那个孩子 → 被问的人；他此刻的心思不在题上
众人 → 替他挡的人；他们不是护他，是怕这一场僵在那里
那处门楼 → 整片地方的正中间，也是这一家人最要紧的脸面
```

**四拍**

1. 到了最要紧的一处，甲当众出题。
2. 众人报了一串最响的好话，甲摇头，不取。
3. 甲叫孩子；孩子仰头看了很久，没有开口。
4. 众人替他挡，甲冷笑，限他一日。

**选择**：由孩子做——硬写一句交上去，还是认下“现在写不出来”。第二个岔路是甲的：限一日，还是当场逼、逼不出来就罚。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【谶：明日】限期一张 | 到期结算：写出来当场结，写不出来另结 |
| 【失】孩子当众失去“什么都能写”的名声 | 被后面的“他还有不会的事”触发 |
| 【恩】替他挡了那一句的众人，这一回是真心替他挡的 | 日后需要有人替他说话时 |
| 【悟】“来过这里”这一念，是他自己心里的事，与这一场考试无关 | 留作后面的私人线索，不必兑现 |

**移植**：古代——游园题匾，到了正殿牌坊，儿子出神，答不上来。现代——竞标答辩，最关键的那一页，主讲人忽然讲不下去，老板说“明天给我”；发布会上，最要紧的那句口号，文案当场卡住。奇幻 / 科幻——宗门大典前题写祭文，弟子在祭坛前失神；星舰命名礼，题名人对着舰徽说不出话。

**禁忌**：不写“他为什么觉得自己来过”——那会滑向超自然，也会把这一张写成宿命。不要写他最后到底写没写出来；也不要写甲是真的要罚，还是留了余地。

**原著锚点**

- 保留：到了全园最要紧的一处，被问的人忽然神思不属，答不上来；众人替他开脱，长辈冷笑，限一日。
- 舍弃：牌坊题字、清客的具体话、“蓬莱仙境”等。
- 原文：“宝玉见了这个所在，心中忽有所动，寻思起来，倒象在那里见过的一般”；贾政道：“限你一日，明日题不来，定不饶你。”
