# C17-10 我还收着

**类型**：翻出旧物 / 收不了场  
**分类**：现实类

## 卡面

那件东西已经破了，剪它的人还在气头上。

那孩子赶过来，一边走一边解衣领，从最里面的衣襟上，解下一样东西来，递到那人面前，说：你瞧瞧，这是什么？我什么时候把你的东西给过别人了？

那人看着那件东西，看见它是贴身穿着的，是收在最里面一层、怕人拿去的那一层。

那人低下头，一句话也不说。

那孩子又说：你也不用剪了。我知道你是懒得给我东西。我连这个也还你，怎么样？

他把那件东西丢到那人怀里去了。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**那孩子为什么先从衣领上解**：他要证明的不是“我给过你东西”，是“我一直收着”。收在最里面那一层，本身就是一句话——他怕人拿去。

**玩家在哪**：玩家可以是那个把东西解出来的人——你走进去，身上还带着那件贴身的旧物，你解不解；可以是那个动手的人，东西摆在你眼前，你认不认这个错；可以是屋里的第三个人，你看着这一幕，谁也没法替他们说话；也可以不在场，事后听说“今天那两个人把话都说到底了”。

**选择**：由那个孩子做——把收在最里面的东西拿出来给她看，还是等她自己消气。第二个岔路是那动手的人：认这个错，还是不认。

**代价**：拿出来，他洗清了自己，也让她当面明白剪错了，这个明白比剪破一件东西更难受；丢过去，这一丢，把“我收着你的东西”变成了“这东西我也不要了”——道理赢了，话也砸了。不拿出来，这一场吵到最后，谁也不知道那件东西其实还在。

**那句话里的刺**：“我知道你是懒得给我东西”——这句话不是安抚，是补上去的一刀。卡不判他这刀补得对不对。

**这是哪**：古代、现代、奇幻、科幻都可以。贴身的信物、夹在钱包里的一张照片、一直没删的一条记录、挂在心口的一块玉——只要“他一直收着，没人知道”这一层在，就成立。

**注意**：卡停在“东西丢进怀里”这一刻。不要写这两个人和好了，也不要写他们真的散了。东西已经掏出来，也丢出去了，两样都收不回去。

## 设计底稿

**戏剧命题**：一件从最里面解出来的旧物，能不能抵掉一刀剪下去的那一下。

**关系槽**

```
那个孩子 → 被冤枉的人；他收着东西的方式，本身就是一句话
剪东西的人 → 剪错了的那一个；她的错当众摆在她眼前
那件旧物 → 贴身穿着的；它证明的不是“我给过”，是“我一直收着”
外头找人的声音 → 上头的人在找这孩子，这间屋子随时会有人进来
```

**四拍**

1. 东西破了，人还在气头上。
2. 孩子解衣领，从最里面一层解出那件旧物，递过去，说：我什么时候把你的东西给过别人了。
3. 那人看见它是贴身的，低下头，一句话也不说。
4. 孩子又说“我连这个也还你”，把东西丢进那人怀里。

**选择**：由那个孩子做——把收在最里面的东西拿出来给她看，还是等她自己消气。第二个岔路是剪东西的人：认这个错，还是不认。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】那件贴身的旧物，是这孩子给出去过、又一直留着的一件东西 | 被后面“他还留着她别的东西没有”触发 |
| 【失】剪破的东西补不回来了 | 不会恢复 |
| 【怨】被丢到怀里的那一下，落在两个人中间 | 喂给后面的“和好 / 翻脸 / 出走” |
| 【悟】剪的人看见了：他一直收着 | 消耗后，她看这件事的方式会变 |

**移植**：古代——解衣领，从贴身衣襟上解出荷包，掷向对方怀中。现代——手机里存了五年的聊天记录、一直夹在钱包夹层里的一张照片、一份从没删过的文件，当面翻出来，再摔回去。奇幻 / 科幻——贴身的护符、刻着字的骨片、一直挂在心口的玉。

**禁忌**：不要写这两个人和好了，也不要写他们真的散了。卡停在东西丢进怀里那一下。更不要写孩子后悔了没有——后悔是下一张卡的火。

**原著锚点**

- 保留：从贴身衣襟上解下荷包给那人看，说明自己从未把她的东西给过人；那人自悔莽撞，低头无语；孩子再说“我连这个荷包奉还何如”，掷向怀中。
- 舍弃：荷包的来历、两个人物的名字，以及下文“拿起荷包又铰”的往来。
- 原文：“因忙把衣领解了，从里面衣襟上将所系荷包解下来了递与黛玉道：‘你瞧瞧，这是什么东西？我何从把你的东西给人来着？’”
