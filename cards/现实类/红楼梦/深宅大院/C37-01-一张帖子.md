# C37-01 一张帖子

**类型**：起意 / 相邀
**分类**：现实类

## 卡面

有一个人病了几天，一直关在屋里。稍好一点，她翻出一沓好纸，给几个人各写了一张帖子。

帖子里先谢那个人来看过她，谢他送的东西，然后说自己晚上睡不着，在廊下站着受了凉，才病倒的。

接着她写：古时候的人在争名夺利的地方，还留着一小块地方，请几个说得来的人一起待着；有时候办个文会，有时候结个社。她说，难道只有男人能这样，我们这些人就不配？

帖子送出去，收到的那个人当场高兴起来，说这个人想得周到，我这就去商量。他到了那里，别人已经先到了。先到的人看见他进来，都笑了，说又来一个。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是写帖子的人。她病刚好，闲得发慌，忽然想起这件事。甲可以是玩家，也可以是玩家的家人、同住的人、一个爱张罗的朋友。

**玩家在哪**：玩家可以就是甲，一沓纸摊在桌上，你要写给谁、写到什么份上；可以是收到帖子的那个人，你把帖子看完，当场就说要去；可以是先到的那些客人里的一个，坐在屋里等着看谁会来；也可以不在场，事后听说“那天有人下了帖子，把几个人都叫去了”。

**这张帖子是什么**：一张写了字的纸，一个人手写的，指名给某几个人。它不是公事，也不是长辈的吩咐，是一句私下的邀约。

**发帖子的人为什么这样写**：她先谢对方来看她，再把自己那点委屈说成病由，最后把这件事抬到“古人也这么办”的高度。写帖子是她的分寸：登门去叫，太像吩咐；托人传话，太随便。写在纸上，就成了一件正经事。

**收到的人为什么立刻就去**：因为这张纸不重，却很客气。它给足了收信人的面子——不是“你来一趟”，是“我扫了地等你”。他若拖一拖，就是拂了这份客气。

**这是哪**：古代、现代、奇幻、科幻都可以。大户人家的小姐们凑个诗社；同事在群里发一段话说“我们搞个读书会吧”；学徒之间约着每月聚一次，各带一样东西来；戏班、道场、星舰上的几个人约着轮流出题。只要“一个人起意，写下来，指名请人”这一层在，就成立。

**注意**：卡停在“先到的人看见他进来，都笑了”这一刻。不要写这场聚会商量出了什么，也不要写谁来了谁没来。**一个人本来只是闲着难受，从这张纸送出去起，她就成了这件事的发起人；后面所有的事，都要记在她的名下。**

## 设计底稿

**戏剧命题**：一句“咱们聚聚吧”，为什么非要写成一张帖子；一个人起了这个意，就把自己架到了什么位置上。

**关系槽**

```
甲 → 起意的人；病刚好，闲得难受，要给自己找一件正经事
收到帖子的人 → 被指名的那一个；他一来，这件事就有了第一个响应的人
送帖子的人 → 甲身边的人；跑腿，也替甲把话递到
先到的人 → 已经坐在屋里的人；他们比收到帖子的人更早到，说明这一场不止请了一个
```

**四拍**

1. 一个人病了几天，好一点，翻出好纸，写了几张帖子。
2. 帖子里谢对方来看她，把病由说成夜里受了凉。
3. 她写：古人还留一小块地方，请几个说得来的人一起待着；难道只有男人能这样。
4. 收到帖子的人当场说“我这就去商量”，到了那里，别人已经先到了。

**选择**：由起意的人做——写这张帖子，还是就想想算了。第二个岔路是收到帖子的人：立刻就去，还是先拖一拖。第三个岔路是已经在座的人：这一场要不要跟着办起来。

**代价**：写出去，她就从一个“闲着的人”变成了“发起的人”，往后这件事出什么岔子都算她的；收回来不写，这一场就不存在，她也就还是那个闲着的人。收到的人去了，是给足这份客气，也等于入了这一摊；不去，这一张纸就白写了，写的人往后不会再写第二张。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】收到帖子的人赴了这一约，欠这一场一次 | 被后面“他开口要办一件自己的事”触发 |
| 【寄】写帖子的人病刚好，日子过得散，靠这一件事把自己撑起来 | 后面她在这件事上栽了，就消耗掉 |
| 【悟】来的人看明白了一件事：这一场不止请他一个 | 消耗后，他会开始留意谁没被请 |

**移植**：古代——深宅里几个年轻的姑娘少爷凑一个文会，一个人下帖子起头。现代——同事在群里说“我们搞个读书会”，一人发一条私信点名请人；小区里几个人约着每月聚一次；同学群里一个人张罗同学会。奇幻 / 科幻——学徒之间约着每月比一次手艺；星舰上的几个人轮流出题，谁起的意谁做东。

**禁忌**：不要把这场聚会写成什么大事，它起头只是一个闲得难受的人的念头。不要写这张帖子上的词句，也不要写后来诗做得好坏。不要把起意的人写成爱出风头的人——她只是想给自己找一件正经事。

**原著锚点**

- 保留：一个人病刚好，写了花笺分别送给几个人，帖中先谢对方探问、馈赠，再叙自己夜里在廊下受了风露；接着援古人结社之例，问“孰谓雄才莲社，独许须眉”；收信人看了拍手笑道“我如今就去商议”，到那里众人已在。
- 舍弃：探春、宝玉、翠墨等人名，秋爽斋等地名，花笺、鲜荔、真卿墨迹等物名，以及帖中“莲社”“东山”等典故与全篇骈俪文句。
- 原文：“妹探谨启二兄文几……孰谓雄才莲社，独许须眉，不教雅会东山，让馀脂粉耶？若蒙造雪而来，敢请扫花以俟。”
