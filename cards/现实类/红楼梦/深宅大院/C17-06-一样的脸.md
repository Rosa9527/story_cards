# C17-06 一样的脸

**类型**：迷路 / 认不出  
**分类**：现实类

## 卡面

那一处屋子，人一进去就分不清东南西北。

四面全是雕花的板，一会儿是窗，一会儿是门，一会儿又成了一架书；往前一步，有一扇窗挡住了去路；退一步，又有别的门开着。

甲往里走，走了两层，就迷了路。

左边看有门能通，右边看有窗隔着；走到跟前，被一架书挡住；回过头，纱帘又透出门径来。

身边的人都不在跟前了。甲也没有开口叫。

甲走到一扇门前，迎面也有一个人走过来，穿的衣服、走路的架子，都和他自己一样。

甲站住了。

那不是人。那是一面极大的镜子。

甲站着，没有动。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是走进去的那个人，也是这处地方的主人。这屋子是他叫人修的，他以为自己熟。

**玩家在哪**：玩家可以是甲——你走进去，走迷了，前头还有一个和你一模一样的人迎着你走过来；可以是跟在后面的一个下人，你站在外圈，眼看着主家在里面转了两圈，不敢叫他；可以是那个知道路的人，众人都等着你开口；也可以不在场，事后听说“老爷在那间屋子里转了半天才出来”。

**那一面镜子照出了什么**：只照出一件事——这屋子不是给人住的，是给人迷路用的。甲自己出钱修的屋子，把他自己也绕进去了。

**选择**：由甲做——站着，还是开口叫人；上前一步看清那张脸，还是转身再找一条路。若玩家占的是后面那个下人的槽，选择就变成“叫不叫住他”：叫了是提醒主家迷路了，不叫就让他自己转出来。

**代价**：开口叫人，等于当众承认自己在这间屋子里不认得路；再转，就得在这间屋子里继续转下去。站着不动的时间越长，外头的人越会往坏处想。

**这是一张喘气的卡**：它不制造冲突，也不留下什么账。它的用处是让人在这处地方站一会儿——这整片地方不是给人住的，是给人看和给人跪的，谁进来都一样。

**这是哪**：古代、现代、奇幻、科幻都可以。迷宫似的宅子、样板间、镜面装置、玻璃幕墙、幻阵——只要“这地方是照着让人迷路的样子修的”这一层在，就成立。

**注意**：卡停在“甲站着，没有动”这一刻。不要写这面镜子有灵性，也不要写甲在镜子前想起了什么。它就是一面做得太大的镜子。

## 设计底稿

**戏剧命题**：一个一辈子要人看着的人，忽然在一面镜子前，看见自己也是被看着的。

**关系槽**

```
甲 → 走进去的人；他一辈子被人看，也一辈子没看见过自己
跟着的人 → 站在外圈，知道路，不敢催
那面镜子 → 不是人，是这间屋子里最诚实的一样东西
```

**四拍**

1. 一行人进了这处屋子，四面都是雕花的板，转两圈就分不清方向。
2. 甲往前走，左边有门，右边是窗，走到跟前又被挡住。
3. 身边的人都不在跟前；甲也没有开口叫。
4. 甲看见前面也走过来一个人，衣裳架子都和自己一样。那不是人，是一面镜子。

**选择**：由甲做——站着，还是开口；上前，还是再找一条路。若玩家占的是跟着的那个人的槽，选择变成“叫不叫住他”。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【悟】甲第一次看见自己也是被人摆布的 | 消耗后，甲看自家那些镜、那些绕人的布置会多看一眼 |
| 【怨】甲怪那个知道路的人不早说这里有这么一面镜子 | 喂给后面的一次发作，很轻 |
| 【失】甲失去了“这屋子是我修的、我熟的”这份从容 | 被 C17-07 接着用：他连自己家有几样东西不齐也答不上来 |

**移植**：古代——游园时走进迷宫似的屋子，被一面大镜照见自己。现代——新装修的样板间、美术馆的镜面装置、游乐场的哈哈镜、玻璃幕墙的大楼。奇幻 / 科幻——迷阵、幻境、全息投影；镜像空间里，人与自己的复制品对峙。

**禁忌**：不要把这面镜子写成有灵性的东西，也不要写它“映出心里的什么”。它就是一面镜子，只是做得太大了。不要写甲在镜前想了什么——卡只写他站住了、没有动。

**原著锚点**

- 保留：走进一处四面雕空、门窗难辨的屋子，迷了路，迎面撞上一面大镜子，看见“与自己形相一样”的人。
- 舍弃：具体院落名、雕花隔断的花样、玻璃镜的位置、引路人的姓名。
- 原文：“及至门前，忽见迎面也进来了一起人，与自己的形相一样，却是一架大玻璃镜。”
