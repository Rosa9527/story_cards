# C20-05 没人向着他

**类型**：出身 / 输赢  
**分类**：现实类

## 卡面

这几天，学里停了课，一家的几个孩子凑在一处掷骰子玩钱，一注几个钱。伺候的姑娘也在旁边看着。

甲家的孩子头一回赢了，很高兴。后来接连输了几盘，就急了。这一盘轮到他掷：掷出七点赢，六点也赢，三点就输。他把骰子狠狠一掷，一个定住了是二，另一个还在转。旁边的姑娘拍着手喊“一点”；他自己瞪着眼喊“六”“七”“八”。骰子偏偏转出一点来。

他急了，伸手把骰子抓起来，说是个四点，就要拿钱。

姑娘说：明明是一点。

带他们的那位姑娘看他要急哭了，就瞪了自家的人一眼，说：越大越没规矩！难道他会赖你这几个钱？还不放下钱来呢。

伺候的姑娘满心委屈，不敢出声，把钱放下，嘴里嘟囔：他这样的身份，还赖我们这几个钱，连我也瞧不起。前两天跟那一位玩，他输了那么多也没着急，剩下的钱还是几个小丫头抢了去，他一笑就罢了。

话没说完，就被喝住了。甲家的孩子说：我拿什么跟他比？你们都怕他，都跟他好，都欺负我出身不如他。

说着就哭。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲可以是玩家，也可以是这个家里的孩子、伺候的下人、带人的那位姑娘。甲必须沾着“这一家里谁高谁低”这件事。

**玩家在哪**：甲可以是那个输了钱的孩子；可以是那个被按住不许出声的下人；可以是带人的那位姑娘，当场决定向着谁；也可以不在场，事后听人学这件事。若甲是那个孩子，卡的重点就是“你终于把最不该说的那句话说了出来”。

**那个孩子在赌什么**：几个钱。可他真正在赌的是“这个家里有没有一条规矩是向着我的”。

**赖账是真的吗**：是真的。卡不洗白他。这张卡的分量不在他有没有错，在他错了之后看见了什么。

**带人的姑娘为什么按住自己人**：因为这是她家、她的人、她要维持的体面。她做得对，也很难看：一个下人当着主子的面，把实话说了出来。

**那句关于出身的话是什么**：正出 / 偏出、亲生的 / 带来的、本家的 / 外来的、老员工的孩子 / 东家的孩子。这句话这个家里从来没人明说过，也从来没人不知道。孩子一说出口，就再也收不回去了。

**这是哪**：任何有“两等孩子”的家庭或组织——老宅、宗族、家族企业、寄宿学校。

**注意**：卡停在“孩子哭了”这一刻。不要写有没有人安慰他、有没有人罚那个下人。一个孩子在自家院子里第一次明白“这一局本来就不是给我赢的”，比输几个钱重得多。
