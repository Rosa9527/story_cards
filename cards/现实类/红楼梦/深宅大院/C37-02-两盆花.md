# C37-02 两盆花

**类型**：送礼 / 认亲
**分类**：现实类

## 卡面

后门上来了一个人，拿着两盆白花，还有一张帖子。这个人年纪比收东西的那位大，辈分却低，只敢在后门外面等着，托看门的把帖子和花送进去。

帖子上，他自称晚辈，先给收东西的人请安，说自从上回认了这门亲，天天想尽一点心，一直没找着机会；这回替人采买花木，认识了不少花匠，才弄到两盆这样的花，别人弄不到。他写：你要是把我当自己孩子看，就留下来摆着；天热，园子里姑娘们进进出出不方便，我不敢当面来。

收东西的人看了帖子，笑了，问来人：他一个人来的？还有别的人没有？来人说：还有两盆花。他说：你出去说，我知道了，难为他想着；把花送到我屋里去就是了。

说完，他转身往别处去了，始终没有见那个人。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是收东西的人。他家里有势，年纪比送礼的人小，辈分却高，一句话就能让一个人在门外站半天。甲可以是玩家，也可以是玩家家里的主人、长辈、当家的那一位。

**玩家在哪**：玩家可以就是甲，帖子在你手上，门外那个人还在等着，你出不出去；可以是送礼的那个人，你只求把东西递进去，见不见得着人要看运气；也可以是看门的，你替两边传话，一句话说错就得挨两边的说；也可以不在场，事后听说“那天有人送了两盆花来，那家的主人收了”。

**那声称呼是怎么来的**：不是真的父子。是先前有一次见面，年长的那一位拿他打趣，说“倒像我的儿子”；说话的人当时顺着就认了，从此在帖子上把自己写成晚辈。这一声是他自己写上去的，不是别人认下的。

**为什么非要送礼**：他图的是这门亲认下来。年纪大、辈分低、手里没有产业的人，靠的就是这一条路：先把称呼喊低，再把东西送上，往后才有开口求事的资格。

**收东西的人为什么不出去见**：不是看不起他，是根本没把这件事当成一件事。他正忙着去赴另一场约，东西收下就够了；门外那个人是谁、等了多久，不在他心里。**这比当面拒绝更冷。**

**这是哪**：古代、现代、奇幻、科幻都可以。族中晚辈给得宠的子弟送东西；实习生给部门负责人送土产，附一张写着“晚辈”的卡片；穷亲戚给当权的亲戚送礼；小门派的人给大宗门送一份厚礼，自称“门下”。只要“有人把辈分喊低、把东西送上，只求一个回应”这一层在，就成立。

**注意**：卡停在“他转身往别处去了，始终没有见那个人”这一刻。不要写门外那个人等了多久、后来有没有走，也不要写这份人情往后有没有用上。东西收下了，那声称呼没有被认，也没有被退——**这就成了往后可以随时拿出来说的一笔账。**

---

## 设计底稿

**戏剧命题**：一个人把辈分喊低了、把东西送上来，收的人不认也不退，这一笔账从此挂在谁身上。

**关系槽**

```
甲 → 收东西的人；有势、辈分高、年纪轻，一句话就能定这件事
送礼的人 → 年纪比甲大，辈分比甲低；只求把东西递进去，见不见得着人看运气
看门的人 → 两边传话的人；他自己没有立场，却要挨两边的说
那两盆花 → 一个由头；收下它，就等于收下了那个人往后开口的资格
```

**四拍**

1. 后门来了一个人，拿着两盆花和一张帖子，只敢在外面等着。
2. 帖子里自称晚辈，写“你要是把我当自己孩子看，就留下来摆着”。
3. 收东西的人看了帖子笑了，问来人：他一个人来的？来人说，还有两盆花。
4. 他说“我知道了，难为他想着，把花送到我屋里去”，说完转身去了别处，始终没有见那个人。

**选择**：由收东西的人做——出去见，还是不见；花收下，还是退回去。第二个岔路是送礼的人：等下去，还是走。

**代价**：收下，他就默认了那个人往后可以拿这件事来开口，这声称呼虽然没有被认，却也没有被退；退回去，他省了往后一桩麻烦，也当面把那个人的脸撕了。送礼的人等下去，是把自己放在更低的位置上；走了，这两盆花就白弄了。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】送礼的人得了“难为他想着”这一句回应，往后可以拿它开口 | 被后面“他上门求一件事”触发 |
| 【人情】那声称呼没有被认，也没有被退，成了一笔悬着的账 | 后面任何一次见面，都可以拿它来算 |
| 【寄】送礼的人没有产业，靠认这一门亲给自己找位置 | 他真从这门亲里得了差事，就消耗掉 |
| 【失】收东西的人失去了“这件事与我无关”这一句 | 消耗后，他再听到这个人的名字，就得表态 |

**移植**：古代——族中晚辈给得宠的子弟送两盆花，附一张帖，自称“不肖男”。现代——实习生给部门负责人送土产，附一张写着“晚辈”的卡片；穷亲戚给当权的亲戚送礼，托门卫递进去；小公司给大客户送一份厚礼，自称“贵公司的小弟”。奇幻 / 科幻——小门派给大宗门送一份厚礼，自称“门下”；佣兵给舰长送一箱私货，只求见一面。

**禁忌**：不要把送礼的人写成谄媚的人——他是在替自己找一条路，这条路他只有这一条。也不要写收东西的人心里怎么想，他不出去见，不是嫌弃，是没把这事放在心上。不要把那声称呼解释成真的亲属关系。

**原著锚点**

- 保留：后门上有人送两盆白海棠并一封字帖，帖中自称“不肖男”，请“父亲大人万福金安”，叙自己如何认得花匠、弄到两盆、不敢面见；收信人看了笑问“他独来了，还有什么人”，随后说“我知道了，难为他想着，你就把花儿送到我屋里去就是了”。
- 舍弃：贾芸、宝玉等人名，怡红院、秋爽斋等地名，白海棠的名目、买办花草的差事，以及帖中骈俪文句。
- 原文：“不肖男芸恭请父亲大人万福金安……大人若视男是亲男一般，便留下赏玩。因天气暑热，恐园中姑娘们妨碍不便，故不敢面见。”
- 附记：原文送来的是白海棠，本回后半的海棠诗社即由这两盆花起头。卡面只写“两盆白花”，把花的名目与后半的诗社全部舍掉——这张卡要的是门外那一个人，不是那两盆花。
