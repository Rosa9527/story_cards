# C37-04 少了一个人

**类型**：想不起 / 去不去叫
**分类**：现实类

## 卡面

这件事办起来了，几个人分头散了。有一个人回到屋里，才觉得心里像少了一件东西，想不起来是什么。

伺候他的人提起：已经打发人给另一个人送东西去了。他听了，拍手说：偏偏把她忘了！我就觉得心里有件事。这件事里要少了她，还有个什么意思。

伺候他的人劝他：什么要紧，不过是玩意儿。她比不得你们自在，家里又做不得主。告诉她，她来又由不得她，不来她又牵肠挂肚的，倒叫她难受。

他说：不妨事，我去跟老太太说，打发人接她去。

过了一会儿，送东西的人回来了，学了一遍那边的话：她说你们办这件事，也不告诉她。急得不行。

他听了，转身就往老太太那里去，立逼着叫人去接。老太太说：今天天晚了，明天一早去。他只好回来，闷闷的。

第二天一早，他又去催。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是想起来的那个人。他一开始忘了，想起之后又非要补上。甲可以是玩家，也可以是这一家里说话管用、又跟那个人最说得来的一个。

**玩家在哪**：玩家可以就是甲，你想起这个人，屋里另一个人正劝你别多事；可以是劝他的那个人，你把难处一条一条摆出来，他一个字也没听；可以是那个被忘在外面的人，你听说他们做诗没叫你，急得不行，可你连出门都要问人；可以是家里做主的那位长辈，两个孩子在你跟前一个要接、一个说天晚了；也可以不在场，事后听说那天为接一个人闹了两趟。

**他为什么非要去叫**：不是为了让那个人高兴，是为了这一场齐全。他觉得少了她就没意思——他要的是热闹，不是她的难处。

**劝的人说的对不对**：是对的，而且劝的人最清楚她的处境。**她告诉了她，她就得来；来不了，她在家那边就要受话。**这张卡里唯一替她想过的，是劝的那个人。

**为什么算重**：这一趟车去接一个人，接来容易，送回去难。她在家里做不得主，出门要交代，回去还要交代；她来了这一趟，那边就有了一笔可以拿出来说的账。**他补上了自己的遗憾，代价记在她身上。**

**这是哪**：古代、现代、奇幻、科幻都可以。几个朋友聚会，快散了才想起少叫一个人，当场打电话去叫；公司团建漏了一个同事，负责人连夜开车去接；同学聚会，有人非要叫上那个家里管得最严的人。只要“一个人被漏下，另一个人非要把她补上”这一层在，就成立。

**注意**：卡停在“第二天一早，他又去催”这一刻。不要写她后来来了没有，也不要写她回去之后怎么样。**被忘的那个人已经在路上了；她这一趟出门，往家里报的时候得自己想办法。**

## 设计底稿

**戏剧命题**：一个人被漏下之后，另一个人非要把她补上，这一补，代价落在谁身上。

**关系槽**

```
甲 → 想起来的人；他先忘了，想起之后非要补，要的是这一场齐全
劝他的人 → 伺候他、也最清楚那个人处境的人；她替那个人想过
被忘下的人 → 不在场；她在自己家里做不得主，出门要问人
做主的长辈 → 手里有车、有人、有准不准的人；她只说了一句“天晚了，明天再去”
```

**四拍**

1. 事情办起来，人散了，甲回到屋里觉得心里少了一件东西。
2. 伺候他的人提起已经给那个人送过东西，甲拍手说“偏偏把她忘了”。
3. 劝的人把难处一条一条摆出来：她做不得主，来由不得她，不来又牵肠挂肚。
4. 送东西的人回来学话，说她急得不行；甲转身去求长辈，当晚没接成，第二天一早又去催。

**选择**：由甲做——现在就去叫，还是听劝算了。第二个岔路是那个被忘下的人：来，还是不来。第三个岔路是做主的长辈：当晚就放车，还是压到第二天。

**代价**：去叫，甲补上了自己的遗憾，那个人却要为这一趟出门在家里交代；不叫，这一场不齐全，那个人从别人口里听说，心里更不好受。那个人来了，欠这边一次，也欠家里一次；不来，她错过了这一场，往后更难开口。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【人情】甲非要补上这一趟，那个人若来了，就记这一次 | 被后面“她替甲办一件事”触发 |
| 【怨】那个人被漏下在先、被叫去在后，这一笔在她自己心里 | 喂给后面的一次赌气 |
| 【失】甲失去了“这一场是齐的”这种安心 | 人到了，就消耗掉 |
| 【谶：那边的话】她家里做不得主，出门总要交代 | 她往后每一次出门，都要拿它来算 |

**移植**：古代——几个朋友凑一场文会，快散了才想起少请一位，当晚就打发车去接。现代——同学聚会漏了一个人，组织者连夜打电话、开车去接；公司团建漏了一个同事，负责人第二天一早去补；婚礼上主家发现少请了一桌亲戚，临时补请。奇幻 / 科幻——小队出任务前发现少叫一个人，队长连夜去请；星舰上的聚会漏了一名船员，舰长非要补上。

**禁忌**：不要把甲写成痴情的人——他要的是这一场齐全，不是那个人的难处。也不要把劝的人写成坏人，她说的是实话。不要写那个人来了以后怎么样。

**原著锚点**

- 保留：宝玉回屋后觉得心里像少了一件事，袭人提起已打发人给湘云送东西，宝玉拍手说“偏忘了他”；袭人劝他“他比不得你们自在，家里又作不得主儿……没的叫他不受用”；宝玉说“我回老太太，打发人接他去”；宋妈妈回来学湘云的话“他们做诗，也不告诉他去，急的了不得”；贾母说“今儿天晚了，明日一早去”，次日一早宝玉又去催逼。
- 舍弃：宝玉、袭人、湘云、贾母等人名，怡红院、秋爽斋等地名，送去的果子、糕点、碟子等物名，以及“做诗”这一层——卡面只说“办这件事”，好让这张卡落在任何一场聚会、任何一趟差事上。
- 原文：“宝玉听了，拍手道：‘偏忘了他！我只觉心里有件事，只是想不起来，亏你提起来，正要请他去。这诗社里要少了他，还有个什么意思！’”
