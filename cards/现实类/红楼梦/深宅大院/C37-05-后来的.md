# C37-05 后来的

**类型**：补入 / 先交东西
**分类**：现实类

## 卡面

那个人赶到的时候，众人已经坐定了。她进门，先说自己来晚了。

众人说：先别给她看别人写的，先说给她听韵脚，她后来的，先罚她按韵写一首。写得好，就让她入伙；写不好，还要罚她做一次东。

她笑着说：你们忘了请我，我还要罚你们呢。就把韵拿来，我虽然不会，只好勉强出丑。让我入伙，扫地烧香我也情愿。

众人见她这样说，更喜欢了，都埋怨昨天怎么把她忘了，忙把韵脚告诉她。

她一心兴头，等不得细想，一边跟人说着话，心里已经写成了，随手拿纸笔录出来。她说：我按韵写了两首，好坏都不知道，不过交差。

众人一句一句看，看一句惊一句，都说：这个不枉写了这一场。她又说：那明天先罚我做一次东，让我先邀一回，行不行？众人说，那更好了。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是后来的那一个。她不在场的时候这件事办起来了，她赶到的时候规矩已经定好。甲可以是玩家，也可以是新来的同事、转来的学生、后来才加入的那个朋友。

**玩家在哪**：玩家可以就是甲，一屋子人等着看你交出来的东西；可以是定下这条规矩的人，你说“后来的要先交一首”，这话一出口就收不回来；可以是已经入了伙的人里的一个，你昨天确实忘了叫她；也可以不在场，事后听说“那天她一个人写了两首，众人都服了”。

**这条规矩是怎么来的**：不是为了难为她。是先前那几个人已经把题目和韵脚都用过了，她来得晚，别人写过的她不能再写，只能按同一套韵另外写。众人把这件事说成“罚”，是让这一场有个说法——不是白让你进来。

**她为什么答应得那么快**：她太想进来了。她当场把话说得很低：扫地烧香我也情愿。**一个人把自己放到最低，别人就不好再拦她。**

**为什么算重**：她这一交，交出去的不只是一首东西，是她在这个圈子里的位置。**“后来的要先交一样东西”，从此就成了这一摊的规矩；往后每一个新来的人，都要过她今天过过的这一道。**这条规矩是拿她的名字立起来的。

**代价**：她当众交了，交得好，众人服；交得不好，当众丢脸，还要再做一次东。定规矩的人立了这一条，往后每来一个新人，都要由他开口说这一句。

**这是哪**：古代、现代、奇幻、科幻都可以。读书会里后来加入的人要先讲一本书；球队里后进队的人先跑一场；新来的同事先做一次汇报；社团招新要过一道考核。只要“一摊事已经办起来，后来的人要交一样东西才能进”这一层在，就成立。

**注意**：卡停在“那明天先罚我做一次东”这一刻。不要写她这两首到底比谁高，也不要写她后来有没有真做东。**她进的这个门，是自己当众写出来的；这条规矩，往后要一直用在新来的人身上。**

## 设计底稿

**戏剧命题**：一摊事已经办起来，后来的人凭什么进去。

**关系槽**

```
甲 → 后来的那一个；赶到时规矩已经定好，她要交东西才能进
定规矩的人 → 已经入了伙的人；一句“先罚他写一首”，就把门槛立了起来
昨天忘了叫她的人 → 心里有愧，所以拦着不让别人先给她看
```

**四拍**

1. 甲赶到，众人已坐定；她进门先说自己来晚了。
2. 众人说先别给她看，先说韵脚，她后来的，先罚她按韵写一首；写得好入伙，写不好再罚一次东。
3. 甲笑着把话说低：你们忘了请我，我还要罚你们呢；让我入伙，扫地烧香我也情愿。
4. 她一边说话一边写成，随手录出两首，众人看一句惊一句；她又说“明天先罚我做一次东”。

**选择**：由甲做——当众交，还是推说自己不会、改天再来。第二个岔路是众人：让不让她进，是当场考，还是先让她进来再说。

**代价**：交，她把自己放到最低，也让这条规矩落在自己名下；不交，她这一趟白来，往后更难开口。众人立了这条规矩，往后每一个后来的人都要过这一道；不立，这一场就没有门槛，谁都能随时插进来。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】众人许她入伙，她记这一份 | 被后面“她替这一摊出力”触发 |
| 【怨】昨天忘了叫她，这一笔在她心里 | 喂给后面的一次赌气 |
| 【谶：后来的先交一首】这一条以后要用在每一个新人身上 | 下一个新人来时结算 |
| 【悟】她看明白：想进来，得先把自己放低 | 消耗后，她往后不再用这一招 |

**移植**：古代——一伙人凑的文会已经开起来，后来的人要先交一首才能入伙。现代——读书会后来加入的人先讲一本书；球队后进队的人先跑一场；新同事先做一次汇报；社团招新要过一道考核。奇幻 / 科幻——行会里后来的人要先交一件活儿；星舰上的牌局，迟到的人先认一轮罚。

**禁忌**：不要写她这两首写得好不好，也不要写众人是不是真服。不要把定规矩的人写成刻薄的人——立这道门槛，是为了让这一场有个说法。也不要在卡面上写出她写的是什么。

**原著锚点**

- 保留：湘云午后赶到，众人说“且别给他看，先说给他韵脚，他后来的，先罚他和了诗。要好，就请入社，要不好，还要罚他一个东道儿再说”；湘云笑说“你们忘了请我，我还要罚你们呢……容我入社，扫地焚香，我也情愿”；她一边与人说话一边和成两首，众人看一句惊讶一句；随后她说“明日先罚我个东道儿，就让我先邀一社”。
- 舍弃：湘云、李纨、宝玉等人名，海棠诗社的名目，两首和诗的全部诗句与韵字。
- 原文：“李纨等因说道：‘且别给他看，先说给他韵脚，他后来的，先罚他和了诗。要好，就请入社，要不好，还要罚他一个东道儿再说。’”
