# C37-06 出不起这份钱

**类型**：许愿 / 兜底
**分类**：现实类

## 卡面

到了晚上，两个人单独在一间屋里，商量这顿饭怎么办。

先开口的是白天当众许下这件事的那一个。她说了一遍自己的打算。听的人听完，说：不行，都不妥当。

听的人接着说：你既然要办，就得做这个主人。这本来是个玩意儿，可也得前前后后都想到——自己不能太吃亏，又不能得罪人，然后大家才高兴。你在家里做不得主，一个月就那么点钱，自己都不够用。为这么点不要紧的事，你那边的人知道了，更要埋怨你。再说，就算你全拿出来，办这一场也不够。难道为了这个回家去要？还是跟这里要？

先开口的那个被这几句话点醒了，就犹豫起来。

听的人又说：我已经有个主意了。我家的铺子里有个伙计，他们地里出的好螃蟹，前几天送了几只来。这里的人，从老太太起，连上房里的人，一多半都爱吃这个。前些日子还有人说要请老太太在园子里赏桂花、吃螃蟹，因为有事，还没请成。你现在先别提请客做东的事，只说请大家来聚一聚；等他们散了，咱们有多少东西不能写？我去跟我哥哥说，要几筐又肥又大的螃蟹来，再到铺子里取几坛好酒，备四五桌果碟子。这样又省事，大家又热闹。

先开口的那个听了，心里服气，极口说这个主意想得周到，就答应照这么办。

听的人又说：我这是一片真心为你的话，你可别多心，别想着我看轻了你，咱们两个就白好了。你要是不多心，我就叫人去办。

先开口的那个忙说：你这么替我打算，我要还多心，那还是个人吗。我要不把你当亲姐姐待，上回家里那些烦难事，我也不肯全告诉你。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是出主意、也出东西的那一个。她家里有铺子、有伙计、拿得出螃蟹和酒，说话又直。甲可以是玩家，也可以是那个手头宽裕、又肯替朋友打算的同事、亲戚、同门。

**玩家在哪**：玩家可以就是甲，你当面把朋友的难处一条一条说破，再说出自己这套办法；可以是那个许下事情的人，你白天话说得太满，晚上才知道办不起；可以是这屋里的第三个人，站在旁边听着；也可以不在场，事后听说“那顿饭是别人替她办的”。

**那件许下的事是什么**：当众答应的请客、做东、摆一桌、办一场。它本来只是顺口一句，可当着人说出来，就成了一件要办的事。

**为什么她办不起**：她在家里做不得主，手里那点钱连自己都不够用；全拿出来也不够办这一场。她要办，只有两条路：回家去要，或者跟这边要——两条路都要她开口欠人。

**甲这套办法好在哪**：她把“做东请客”换成了“请大家来聚一聚，顺便请长辈赏花吃螃蟹”。名目一换，钱就是甲出的，东西是甲家的，那个人不用回家开口，也不用跟这边要；她要的东西还在——人来了，聚了，热闹了。**替人兜底，兜的不只是钱，是那个人开口的难处。**

**代价**：那个人欠甲一次，而且这一场从头到尾不是她的，往后提起来，说的是甲家的螃蟹、甲家的酒。甲出钱出东西，还担着“我替你办”的意思——她自己也清楚，所以东西还没出手，先补一句“你可别多心”。这一句是给出去的，也是划下来的：往后那个人再提这件事，就先欠了这一句人情。

**这是哪**：古代、现代、奇幻、科幻都可以。朋友当众说要请大家吃饭，回头发现手头不够，另一个朋友说我家里有现成的，借个名目办了；同事说要做东团建，预算批不下来，主管说用部门的名义办；同门说要请客，师兄说我铺子里有货。只要“一个人许下办不起的事，另一个人拿自己的东西替她圆上”这一层在，就成立。

**注意**：卡停在“我要不把你当亲姐姐待，上回家里那些烦难事，我也不肯全告诉你”这一刻。不要写这顿饭后来办得怎么样，也不要写那个人还欠不欠甲这一份。**她要的东西一样没少，只是从此这一场不姓她的姓了；而且为了让这一场办成，她还当众交出了自己家里的事。**

## 设计底稿

**戏剧命题**：一个人当众许下办不起的事，另一个人拿自己的东西替她圆上——这份好意，欠的人怎么还。

**关系槽**

```
甲 → 出主意、也出东西的那一个；家里有铺子有伙计，拿得出螃蟹和酒
许下事情的人 → 白天话说得太满的那一个；在家里做不得主，手里没有钱
铺子里的伙计 → 甲家的下人；地里出的好螃蟹，是他的来路
哥哥 → 甲家里的当家人；甲要的东西，得由他发话
```

**四拍**

1. 晚上两个年轻女子单独在一间屋里，商量这顿饭怎么办；先开口的说了一遍自己的打算。
2. 甲听完说“都不妥当”，把难处一条一条摆出来：你做不得主，钱不够，回家要、跟这里要都不行。
3. 甲说“我已经有个主意了”：铺子里的伙计有好螃蟹，这里一多半人爱吃；先别提做东的事，只说请大家聚一聚。
4. 甲说她去跟哥哥要螃蟹、取好酒、备果碟，那个人服气，答应照办；甲又先补一句“你可别多心”，那个人忙说自己不会多心，还把“上回家里那些烦难事都告诉过你”拿出来作证。

**选择**：由许下事情的人做——接甲这套办法，还是自己想办法把话说圆（回家要、跟这里要、或者干脆不办）。第二个岔路是甲的：替她兜这一底，还是让她自己去碰。

**代价**：接了，她不用开口求人，可这一场从此是甲办的，她欠甲一次，往后提起来没她的名字；而且为了让这一场办成，她还得当众应下“我没有多心”，把自己家里的事拿出来作保。不接，她要么回家去要，要么跟这里开口，两条路都要她低一次头。甲兜了底，出钱出东西，还担着“我替你办”的意思，所以东西还没出手，先得把对方的脸面安顿好。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】许下事情的人欠甲一次，往后要还 | 被后面“她替甲办一件事”触发 |
| 【人情】这一场办成了，可名目是甲家的 | 后面谁提起这顿饭，都可以拿它来算 |
| 【寄】许下事情的人在家里做不得主，手里没有钱 | 她往后每一次请客、送礼，都要拿它来算 |
| 【悟】她看明白：话说出去容易，兑现要钱 | 消耗后，她往后当众不再许这种事 |
| 【失】她当众交出了“上回家里那些烦难事都告诉过甲”这一句 | 喂给后面“她家里的事被别人知道了” |

**移植**：古代——朋友当众说要请一社，回头发现手头不够，另一个朋友说我家铺子里有现成的，借个名目办了。现代——朋友说请大家吃饭，另一个说我家里有现成的，借个名目办了；同事说要做东团建，预算批不下来，主管说用部门名义办；同门说要请客，师兄说我铺子里有货。奇幻 / 科幻——行会里有人说要摆一桌，另一位说我家有货，用我的名义办；星舰上有人说要请大家，另一位调了配额来补。

**禁忌**：不要把甲写成施恩的人——她替人兜底，也顺手把这一场变成了自己的；这两样同在。不要写这顿饭后来办得怎么样，也不要写那个人还不还这一份。更不要在卡面上把“出钱”写成“施舍”。

**原著锚点**

- 保留：湘云灯下与宝钗计议如何设东拟题，宝钗听完说“皆不妥当”，指出她“家里你又做不得主，一个月统共那几吊钱，你还不够使”“你就都拿出来，做这个东也不够”；随后拿出主意——当铺伙计地里出的好螃蟹、铺子里的好酒、四五桌果碟子，并说“你如今且把诗社别提起，只普同一请，等他们散了，咱们有多少诗做不得的”；湘云“心中自是感服，极赞想的周到”；宝钗又补一句“我是一片真心为你的话，你可别多心”，湘云回说“我要不把姐姐当亲姐姐待，上回那些家常烦难事，我也不肯尽情告诉你了”。
- 舍弃：宝钗、湘云等人名，蘅芜院、稻香村等地名，当铺、螃蟹、桂花、果碟子的具体名目与数目，以及下文拟菊花题的全部内容。
- 原文：“宝钗又笑道：‘我是一片真心为你的话，你可别多心，想着我小看了你，咱们两个就白好了。’湘云忙笑道：‘好姐姐！你这么说，倒不是真心待我了……我要不把姐姐当亲姐姐待，上回那些家常烦难事，我也不肯尽情告诉你了。’”
