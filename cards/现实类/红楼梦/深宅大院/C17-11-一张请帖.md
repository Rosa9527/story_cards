# C17-11 一张请帖

**类型**：相请 / 逼请  
**分类**：现实类

## 卡面

这一家要办一件大事，各处都添了人。添做场面的、添女孩子的、添念诵的、添侍候的，一样一样，都有了着落。

只差一处。有人来回：城西一处小院里，住着一个不出门的姑娘，原是读书人家出身，小时候总也不好，家里想尽了办法都不中用，最后把她送去别处清修才算好，所以带发修行。今年十八岁。

她父母都没有了，身边只有两个老仆和一个小丫头。

她的师父去年冬天走了。走之前留下一句话：不要回乡，在这里静候，自有结果。

所以她一直没有回去。

来回报的人又添了一句：她说过，那种人家必拿身份压人，她不去的。

听的人说：既是读书人家的姑娘，自然要有些脾性。下一张请帖，请她来便是。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**说话的是谁**：这一家的主母。她要办一件大事，各处都要齐整；她不是仗势的人，她用的是“礼”——下一张请帖，比派人去叫更周到，也更不容推。

**玩家在哪**：玩家可以是主母——你退了这一步，把“请”字写在纸上；可以是那个被请的人，你守着一句遗言，也守着一身脾气；可以是来回话的那个管事，你夹在两边，一句话说差就要跑第二趟；也可以不在场，事后听说“那家下帖子请了城西那位姑娘”。

**那个“结果”是什么**：卡里不解释。它是她留着不出门的一件凭据，也是她不必动的理由。要演，就演她守着它；至于它真不真，是桌上算的。

**选择**：由主母做——发这张请帖，还是算了。第二个岔路是那个被请的人：接帖子，还是照旧推。

**代价**：发帖子，主母是退了一步，面子上很好看，可这一张纸上写的是“请”，落下去的意思却是“这一家的体面，不能因为一个人破例”；她若接了，是给了主母面子，她若再推，就是驳主母本人。算了，这场大事办得成，只是少一个该到的人，往后这一家再有这样的事，也不会再来问了。

**这是哪**：古代、现代、奇幻、科幻都可以。大户人家办大事去请一位难请的客、公司开年会请一个早就不露面的人、新栏目开播去请一位多年不接受采访的人——只要“请”这个字本身就带着“非来不可”的分量，就成立。

**注意**：卡停在“下一张请帖，请她来便是”这一刻。不要写她到底来不来，也不要写主母心里是不是真敬着她。这张纸一出，事情就从“人家想不想来”变成了“人家给不给这个面子”。

## 设计底稿

**戏剧命题**：一个人是被“请”来的，还是被一层一层的东西推过来的。

**关系槽**

```
甲 → 被请的人；她不出门，是因为一句话，也是因为一个脾气
说话的人 → 这一家的主母；她要办一件大事，各处都要齐整
来回话的人 → 跑腿的管事；她办了这件差，就有一份体面
那张请帖 → 不是请求，是把“请”这个字写得比“叫你”更狠一点
老师的遗言 → 一张不出门的凭据，或者一个不肯动的借口
```

**四拍**

1. 这一家要办大事，各处一样一样都添齐了。
2. 只差一处：一个小院里住着一个不出门的姑娘。来人从头到脚说了一遍她的来历。
3. 转述她说的话：“那种人家，必拿身份压人，我不去的。”
4. 主母说：既是读书人家的姑娘，自然要有些脾性；下一张请帖。

**选择**：由主母做——发这张请帖，还是算了。第二个岔路是那个被请的人：接帖子，还是照旧推。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】主母这一让，她若领了，便欠这一家一次 | 被后面“她在这府里第一次开口求人”触发 |
| 【怨】她若再推，主母记下这一次驳面子 | 喂给后面的一次冷遇 |
| 【谶：请帖】一张写下去就得有结果的纸 | 被请的人进府之后，这张纸才真正生效 |
| 【寄】她的日子过在一间小院里，靠的是那一点旧门第和一身本事，别的一概没有 | 消耗 C17-12 留下的【寄】 |

**移植**：古代——大户人家办大事，各处添人，去请一位出名难请的客。现代——公司开年会，请一位早就不露面的人；新栏目开播，去请一个出过事、多年不接受采访的人；婚礼上，主家执意要请一位不肯来的长辈。奇幻 / 科幻——宗门大典要请一位避世的老修士；王庭加冕礼，去请一位退隐的星图学者。

**禁忌**：不要把主母写成仗势逼人的人——她用的是“下一张请帖”，那是礼，也是逼，两样同在。也不要写被请的人到底来不来。更不要在卡面上解释那个“结果”是什么。

**原著锚点**

- 保留：办大事各处添人，只差一个不肯出门的人；来人报她的出身、旧病、出家的缘由、师父的遗言；又转述她说“侯门公府必以贵势压人，我再不去的”；主母说“就下个请帖请他何妨”。
- 舍弃：人物姓名、地名、寺名、以及那些经文与遗迹的名目。
- 原文：“若请他，他说：‘候门公府，必以贵势压人，我再不去的。’王夫人道：‘他既是宦家小姐，自然要性傲些。就下个请贴请他何妨。’”
