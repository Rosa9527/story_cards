# C17-08 替我拿着

**类型**：赏 / 被剥  
**分类**：现实类

## 卡面

那孩子从里头出来，脸上还带着一点光。

一出门，跟着他的人都围上来，说：今日上头那位喜欢，老人家打发人出来问了好几遍，我们都回说喜欢。要不是这样，老人家早叫你进去了，哪能显本事？人人都说你的那些话比众人都强，今儿得了赏，该赏我们了！

围着的人不依：把身上的东西赏了罢。

说着，一个个都上来，解下他身上佩的东西，不容分说。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**那个孩子是谁**：他刚在人前得了一句夸。他是这一家里被捧着的那个，也是被人伺候着长大的那个。玩家可以就是他——一群伺候你的人围着你，你要给，还是不给。

**玩家在哪**：玩家可以是那个孩子；可以是伸手的其中一个——你知道他身上有东西，你也知道你伺候了一场该分一点；可以是站在远处看着的那个人，你身上什么也没被解走；也可以不在场，事后只听说“今天少爷身上的东西被他们分光了”。

**他们为什么敢伸手**：这不是恶仆。这一场是他们伺候出来的，伺候一场要点东西，是这地方的规矩。他们先夸，再要，最后不容分说——三步是一套的。

**这件事的时机**：就在他刚得了一句夸之后。人正在高兴里，最不经人围。

**选择**：由那个孩子做——给钱，还是给身上的东西；给到哪一件为止，拦不拦。

**代价**：由着人解，这些人高兴了，可他从这一刻起欠了一样东西的账——那件东西不是他买的，是有人替他收着的。拦，这一屋子人当场就没趣，他们是伺候他的，拦了他们，往后这一路就不好走。只给钱，一吊钱在这些人眼里不算什么，回去还会说这孩子小气。

**这是哪**：古代、现代、奇幻、科幻都可以。席散之后、演出之后、比赛之后、述职之后——只要“刚被捧过的人身上带着东西，旁边是一群伺候他的人”这一层在，就成立。

**注意**：卡停在众人“不容分说”围上来这一刻。不要写他给不给、拦不拦，也不要写这些人是不是太过分。他身上还剩几样，会有人看见，也会有人记住。

## 设计底稿

**戏剧命题**：一个人被一群人围着夸，他自己身上还剩几样东西是自己的。

**关系槽**

```
那个孩子 → 刚在众人面前出了一回风头，此刻还在那股劲里
跟着的人 → 底下人；他们伺候这一场，也就指着这一场得点东西
里头等着的老太太 → 一句话就能叫这孩子进去的人，也是他不敢让人家不高兴的人
身上的佩物 → 有人给他做的，他自己收在最里面的，也有随手带着的
```

**四拍**

1. 孩子从里头出来，脸上带着光。
2. 跟着的人一拥而上，先夸，再说“该赏我们了”。
3. 孩子说每人一吊；众人嫌少，改要他身上佩的东西。
4. 不容分说，荷包、扇袋，一件件解走；众人又拥着他送到老太太门前。

**选择**：由孩子做——给钱，还是给身上的东西。给钱，一人一吊，打发得过去；给东西，就是当众由着人解。还有一条岔路：解到哪一件为止，他拦不拦。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【失】孩子身上的一件佩物，落到了别人手里 | 被 C17-09 直接触发：屋里的人一眼就看见了 |
| 【恩】这些人送了这一场，记着这孩子大方 | 日后这些人肯不肯替他遮掩一回 |
| 【怨】被薄待的那几个：一吊钱没够，东西也没轮到 | 喂给后面的一次背后说话 |
| 【寄】他在这府里的体面，是这些人一句一句捧起来的，也是他们一只手一只手拆下来的 | 消耗《住进来的人》留下的【寄】 |

**移植**：古代——少爷从席上下来，跟班的小厮解荷包、扇袋。现代——演出结束，围上来的人顺手把他的东西分了；实习生刚被老板夸过，回来就被同事把桌上的东西拿走；散场后被助理们“顺手”分掉伴手礼。奇幻 / 科幻——试炼归来，随从分战利品；修行者出关，侍者索要法器。

**禁忌**：不要把这些人写成恶仆——他们是伺候的，伺候一场要点东西，是这地方的规矩。也不要写孩子生不生气；卡只写他身上空了。

**原著锚点**

- 保留：从长辈处出来，跟的人先报“老爷喜欢”、再说“该赏我们了”，先要钱、后要身上的佩物，不容分说解去，又“好生送上去”。
- 舍弃：荷包、扇袋的具体样式，长辈与贴身丫头的对答，以及“每人一吊”的数额。
- 原文：“说着，一个个都上来解荷包，解扇袋，不容分说，将宝玉所佩之物，尽行解去。”
