# C37-03 谁管事

**类型**：立社 / 分事
**分类**：现实类

## 卡面

几个人坐在一起，商议这件事怎么办。有一个人先开口：要办，就得有个章程，我自举我管这一摊。

她说：我那里地方大，就在我那里办。我做主人，也要做这个头儿。一个头儿不够，再请两个人做副手，一个出题定韵，一个誊抄、看场子。

她又说：我们里头有三个人本来不会做诗，这三个人各自分一件事；四个人照旧做诗。要是碰上容易的题目，我们三个也随便写一首。事情就这么定：依我的，就办；不依我的，我就不凑这个热闹。

众人都说这样好。有两个人本来就不爱做诗，听了这话更合心意，都说“很对”。

起头出主意的那个人笑了，说：我起了个主意，倒叫你们三个人管起我来了。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是自举管事的那个人。她不会做诗，可是她最公道、也最肯出头。甲可以是玩家，也可以是家里那个不上场、只管事的当家人、嫂子、年长的同辈。

**玩家在哪**：玩家可以就是甲，当着一屋子人把自己摆到管事的位置上；可以是起头出主意的那个人，你只想着热闹一场，回头发现规矩是别人定的；可以是那两个不爱做诗、顺水推舟的人里的一个，你乐得把差事交出去；可以是那四个要做诗的人里的一个，你本来只想写诗，现在得听人安排；也可以不在场，事后听说“这一摊归谁管了”。

**她为什么要管这一摊**：因为不管，她就没位置。她不会做诗，坐在这儿只能看别人热闹；一管事，她的话就成了规矩。她给自己找的不是权力，是一个能待下去的地方。

**她为什么把不会做诗的人也算进来**：这一手把“不会”变成了“有事做”。那几个人本来坐着不好意思，现在各自有差事，就都留下来了。这一摊能立住，靠的是这个安排，不是靠诗。

**她为什么说“不依我的我就不凑热闹”**：这不是赌气，是定条件。她要的是先答应，再办事；话说成这样，别人就没法先答应了再改。

**代价**：她接了这一摊，往后这一摊里所有人的脸面都要她担；出题定韵、誊抄看场的人，从此不能只当客人；起头出主意的那个人，把主意交出去了，这件事往后不再由她说了算。

**这是哪**：古代、现代、奇幻、科幻都可以。几个人凑一个社、一个读书会、一个球队、一个兴趣小组；公司里几个人搞一个项目，会上有人自荐做负责人；小区里几个人张罗一件事，最后是嗓门最大的那位定规矩。只要“有人起意，有人接过来定规矩”这一层在，就成立。

**注意**：卡停在“我起了个主意，倒叫你们三个人管起我来了”这一刻。不要写这个规矩后来执行得怎么样，也不要写起头的人服不服。**这件事本来是闲得难受时想出来的，从这几句分工起，它变成了一摊有主的事。**

## 设计底稿

**戏剧命题**：一个不会做诗的人，怎么在一场做诗的事里给自己找到位置。

**关系槽**

```
甲 → 自举管事的人；不会做诗，最公道，也最肯出头
起意的人 → 出主意的人；主意一出，就交到了别人手里
不做诗的两个人 → 被分到差事的人；他们本来坐着不好意思，现在各自有事做
做诗的四个人 → 被定下规矩的人；他们只想写诗，从此要听人安排
```

**四拍**

1. 众人商议怎么办，甲开口自举管这一摊。
2. 甲定下地方、主人、正副手的数目和各自的分工。
3. 甲把三个不会做诗的人各分一件事，四个做诗的人照旧做诗。
4. 甲说“依我的就办，不依我的我就不凑这个热闹”；众人说好，起意的人笑说自己反被管起来了。

**选择**：由甲做——接这一摊，还是坐着看别人热闹。第二个岔路是起意的人和做诗的人：依她这套，还是另起一套。

**代价**：接过来，这一摊里所有人的脸面往后都要她担，她也再不能只当一个看客；不接，这场热闹里没有她的位置，她连坐着都坐不安稳。起意的人依了，主意就不算她的了；不依，这一场刚起来就要散。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【恩】那三个不会做诗的人各得了一件差事，往后要记甲这一份情 | 被后面“他们替甲说话”触发 |
| 【怨】做诗的四个人从此要按甲的规矩来，心里有不服 | 喂给后面的一次顶撞 |
| 【寄】甲不会做诗，位置是管出来的 | 她真做出了一首像样的，就消耗掉 |
| 【失】起意的人失去了“这件事由我说了算” | 消耗后，她往后不再张罗这一摊 |

**移植**：古代——几个人凑一个社，不会做诗的那位自举做管事，把题目、誊录、看场子分派下去。现代——同事搞读书会，一个不爱发言的人主动做组织者，排期、定书、记纪要；几个朋友组球队，不会踢的那位管报名和场地；小区里张罗一件事，最后是嗓门最大的那位定规矩。奇幻 / 科幻——学徒社里，不会打的那位管排班；星舰上的娱乐小组，不会玩的那位定规则。

**禁忌**：不要把甲写成爱抓权的人——她是给自己找一件能待下去的事。不要写这场聚会后来办得怎么样，也不要写起意的人服不服。更不要在卡面上解释“管事”有什么好处。

**原著锚点**

- 保留：李纨自举掌坛，说稻香村地方大、就在她那里作社，她要作东道主人兼社长，再请两位副社长，一位出题限韵、一位誊录监场；三个不会做诗的各分一件事，四个要做诗的照旧限定；又说“是这么着就起，若不依我，我也不敢附骥了”；探春笑说“好好儿的我起了个主意，反叫你们三个管起我来了”。
- 舍弃：李纨、探春、迎春、惜春等人名，稻香村、菱洲、藕榭等名号，作诗的具体题目与韵脚，以及罚约、日期等后文条目。
- 原文：“我那里地方儿大，竟在我那里作社……还要推我做社长，我一个社长自然不够，必要再请两位副社长……是这么着就起，若不依我，我也不敢附骥了。”
