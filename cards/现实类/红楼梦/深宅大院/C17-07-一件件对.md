# C17-07 一件件对

**类型**：当众对账 / 不齐  
**分类**：现实类

## 卡面

走到一处屋子前面，甲忽然站住了。

甲问管事的人：屋子、家什都有了，那些帐子、帘子、桌上铺的、床上罩的，可都配齐了？

管事的人回话说：家什早添了许多，到用的时候自然现摆。帐幔帘子那一头，是另一个人管的；听说还不全。

甲就不走了。甲叫人把那个管事的叫来。

人来了，甲问：一共几样？到了几样？还欠几样？

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**甲是谁**：甲是验收的人，也是这一家的长辈。他一路看下来都还满意，到这一处忽然想起东西不齐——他不是要挑毛病，是这处地方再过些日子就要用了。

**玩家在哪**：玩家可以是那个被叫来对账的人——你身上就揣着那张单子，主家当众问你三个数；可以是先被问的那个管事的人，你把话推给了别人；可以是跟着走的下人，站在外圈看这一场；也可以不在场，事后听说“那天老爷问了几样东西齐不齐”。若玩家就是那个对账的人，卡的重点变成“你自己写下的那张单子，你照着报，还是先把总数说圆”。

**那个“秋天”是什么**：那个人自己说出来的期限。他不是被逼的，是自己给自己定了日子——这一句话一出口，就归他自己了。

**选择**：由那个对账的人做——照单实报，还是先把总数说圆。第二个岔路是甲的：问到底，还是就此放过。

**代价**：实报，他当众把“还欠”两个字交到甲手里，这一摊不齐的责任从此有一半记在他名下，也等于替自己定了一个期限；说圆，这一场过得去，日后各处逐一核对，一件件都要翻回到今天这张单子上。甲放过，就是自己也认了“先凑合着办”。

**这是哪**：古代、现代、奇幻、科幻都可以。验收新宅、交付前的例会、开业前查库存、神殿落成点法器——只要“有一张单子，当众报，报不完”这一层在，就成立。

**注意**：卡停在“一共几样？到了几样？还欠几样？”这一刻。不要写那些东西是什么、值多少；也不要写那个人怎么答、到底齐没齐。这一张给桌上留下的，是一个悬着的问题。

## 设计底稿

**戏剧命题**：一个被叫来对账的人，当他自己的单子上写着“还欠”两个字，他还能不能对得下去。

**关系槽**

```
甲 → 问话的人；他要的不是答案，是一屋子东西都有个着落
那个被叫来的人 → 管这一摊的；东西不齐，他有一半责任，也有一半不是他的
举荐他的人 → 当初把这一摊交到他手上的人；此刻不在场，或者就在甲身后
那张单子 → 他一年来的账；写到一半，写不下去了
```

**四拍**

1. 甲走到一处屋子前站住，忽然问起帐幔帘子有没有配齐。
2. 管事的人说那一路是别人管的，听说还不全。
3. 甲不走，把那一路的人叫来，连问三个数。
4. 那个人摸出单子，一样一样报；报到中间，甲不说话；报到末尾，他自己慢下来，说“秋天都全”。

**选择**：由那个被叫来的人做——照单子实报，还是先把总数说圆。第二个岔路是甲的：问到底，还是就此放过。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【谶：秋天】一样东西的齐全，有了一个期限 | 到期结算：全了是应当，不全是他错 |
| 【怨】被当众问到底的人，记着这一回 | 喂给后面的一次推诿、一次使绊子 |
| 【失】甲失去了“这一摊已经办妥”的安心 | 消耗后，甲会开始留意别的摊子 |
| 【恩】那个肯说“还不全”的管事，替甲把话挑明了 | 日后甲要用人的时候 |

**移植**：古代——验收新宅，当众对陈设账目。现代——交付前验收，老板临时查物料清单；工地例会，甲方点名问还差多少；开业前查库存。奇幻 / 科幻——神殿落成验收，执事对法器清单；星舰交付，舰长查配件存量。

**禁忌**：不要写那些东西是什么、值多少钱——这一场的重量在“几条几个”和“秋天都全”这一句上，不在账目本身。不要把甲写成抠门的人，他问的是“到日子能不能用”。

**原著锚点**

- 保留：长辈忽然想起陈设不全，叫来管这一摊的人，当众问“共有几宗、得了几宗、尚欠几宗”；对方取出一张折子照单回报，报出“每样得了一半，秋天都全”。
- 舍弃：具体的帘幔名称、数目、料子，以及两个管事人的分工与姓名。
- 原文：那人“忙向靴筒内取出靴掖里装的一个纸折略节来，看了一看”回报；“每样得了一半，也不过秋天都全了”。
