# C17-12 再等一年

**类型**：守着一句话 / 算卦  
**分类**：现实类

## 卡面

那个姑娘从小身体就不好。家里人请人看过、许过愿，该试的法子都用遍了，全都不管用。

后来有一位算命的替她看了一回，说：这个孩子留不住，不如送出去寄养。

她就这样被送了出去。人居然也好了。她没有削发，只算是修行，还留着一头头发。

父母后来都没有了。她身边只剩下两个老仆和一个小丫头。

她的师父专会算这些。去年冬天，师父也走了。

走之前，师父留下一句话：这个人不宜回乡，在这里静候，自有结果。

她就没有回去。一年了，她一直在这座城里住着，等那个结果。

有人来请她的时候，她推了，说：这种人家，必拿身份压人，我不去。

这话传了回去。过了两天，人家送了一张请帖来，是备了车来请的。

## 注意事项

**合理化**：先确认这件事在玩家这个世界里说得通——人物、地点、时机都要合理。如果玩家在场不合理，就让他完全不出场，事后从别人口中听说。不要为了把玩家塞进场景而硬编。

**玩家在哪**：玩家可以是那个守着话的人——车轿停在门口，你上不上；可以是来接的人，你备了车轿，人家不出来，你回去怎么回话；可以是她身边的那个老仆，你伺候了她这些年，你知道她为什么不动；也可以不在场，事后听说“那位姑娘还是没有出门”。

**那句话是谁说的**：一个已经死了的人。她守着它，是因为说这话的人走了以后，再没有人能替这句话负责。

**卡里不判它对不对**：那句话可以是一位老人的一个判断，也可以是她自己给自己找的一个不必动的理由。桌上要演的是“她守着”，不是“它准不准”。

**选择**：由她做——跟来接的人走，还是守着那句话再等一年。

**代价**：走了，她守了一年的东西从这一天起不算数；出门之后，她的身份、脾气、体面，都要在人家屋檐底下重新分一次。不走，车轿回去，这一家从此不会再请她第二回，她还得替这一年找一个说法——是那句话说得对，还是自己怕了。

**这是哪**：古代、现代、奇幻、科幻都可以。算命的说这孩子留不住、送去别处养、多年以后一位医生或老师留下了一句话、有人来请她出山而她说“那种地方必拿架子压人”——只要“一句死去的人留下的话，管着一个活人的路”这一层在，就成立。

**注意**：卡停在“车轿停在门口，她还没有动”这一刻。不要写她最后上没上车。这一张给桌上留下的，是一句要兑现的话。

## 设计底稿

**戏剧命题**：一个人守着一句死去的人留下的话活着，这句话到底是她的路，还是她的牢。

**关系槽**

```
甲 → 守着那句话的人；她把自己十年来的安稳，都记在那句话和那一次“送出去”上
师父 → 说这话的人，已经不在了；他说一句话，管了甲的后半生
来接的人 → 备了车轿来的；他不是来问的，是来接的
那句遗言 → 既是甲不出门的凭据，也是她不必做任何决定的借口
```

**四拍**

1. 甲小的时候总也不好，家里人什么法子都试过——请神、拜佛、买替身。
2. 有人给她算了一回，说这孩子留不住，不如送出去出家；甲出了家，人就好了。
3. 父母都没了，师父也没了；师父临死留下一句：不宜回乡，在此静候，自有结果。
4. 甲就一直等着。这一回人家备了车轿来，请帖也到了门前。

**选择**：由甲做——跟来接的人走，还是守着那句话再等一年。

**标记**

| 产出 | 可消耗 |
|---|---|
| 【谶：自有结果】一句遗言，指定了一个地方、一段时间 | 被 C17-11 触发；车轿到了门口，这句话必须当场兑现一次 |
| 【悟】甲第一次不得不问自己：等的是结果，还是等一个不必动的理由 | 消耗后，她往后再等就得更明白地说服自己 |
| 【失】父母、师父都没了；能替她拿主意的人，一个也不剩 | 不会恢复 |
| 【寄】她的安稳，是托在一句已经没有人能替它负责的话上的 | 被 C17-11 消耗：她若进府，这份安稳就换了地方 |
| 【恩】那个替她试遍了法子、最后把她送出去的家，早就散了 | 已无可消耗，只作来历 |

**移植**：古代——自幼多病，算命的说留不住，送去出家带发修行；师父临终留下一句“不宜回乡”，就一直留在原地。现代——从小就生病，家里请人看过，说这孩子克父母，送去别处养；多年以后一位医生留了一句话，她就一直没有搬家；有人请她出山，她说“那种地方，必拿架子压人”。奇幻 / 科幻——命盘批出“此子不宜留家”，送入道观；老修行圆寂前留下一句“在此静候”；教团来请，她按着那句话推了。

**禁忌**：不写那句话是真是假。它可以是一位老人的一个判断，也可以是一个借口——卡只管这个人守着它。不要把它写成真的谶；这一回不做成谶语，只写成“一句她要守的话”。

**原著锚点**

- 保留：幼时多病、买替身不中用、到底出家才好；带发修行；父母俱亡，只剩两个老嬷嬷并一个小丫头；师父精演先天神数，去冬圆寂，遗言“不宜回乡，在此静候，自有结果”。
- 舍弃：人物姓名、家乡、家世、寺院名，以及经文与遗迹的名目。
- 原文：“他师父精演先天神数，于去冬圆寂了。遗言说他：‘不宜回乡，在此静候，自有结果。’所以未曾扶灵回去。”
